Always run `ls -la` to see hidden files and folders. 

> Also check the following:

```
history
```
 
```
cat .bash_history 
```

```
cat .bashrc
```

```
env
```

> Directories and files to check for:

```
/opt
/tmp
/var/www/html
/var/tmp
/dev/shm
```

Always check unusual files in home directories as they most likely have some kind of useful information.
